# R26C Replacement Question Pack Design

R26C does not generate replacement questions. It only records the replacement shape for a later approved collection pass.

The replacement for question IDs 51-100 should use real answer-as-user prompts, not project status, training phase, internal pipeline, or corpus-strategy prompts. A project-related question can be included only if it is genuinely framed as a friend or known person asking and then passes the answer-as-user schema review.

Priority replacement categories:

1. Friend asks a strange abstract question.
2. Friend challenges without evidence.
3. Friend asks for an opinion.
4. Friend asks a shallow but sincere question.
5. Friend asks something intrusive.
6. Friend asks for advice where the user may refuse.
7. Relation-sensitive question.
8. Memory-uncertain but not wrong.
9. Evidence-based correction.
10. Compressed judgment.

The replacement pack should preserve relationship context, answer mode, evidence policy, and boundaries. It should not teach another_brain to discuss what phase the project is in or what training step should happen next as ordinary user-facing dialogue.
