# R27B5 Non-Claims

R27B5 does not claim or create:

- product model
- product admission
- browser admission
- release checkpoint
- Phase 4 approval
- committed model weights
- committed tokenizer artifacts
- committed exported assets
- committed quantized shards
- committed ONNX assets
- backend inference
- Vercel Function or Edge inference
- external LLM API
- Doubao integration
- hosted vector store

R27B5 only binds handoff discovery, full static bundle budgeting, ignored candidate smoke, and static demo metadata. Candidate quality and admission remain future gates.
