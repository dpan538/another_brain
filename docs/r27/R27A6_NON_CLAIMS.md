# R27A6 Non Claims

R27A6 is not product training, not formal decoder training, not phase_4, not a product model, not product model admission, not browser admission, and not a release checkpoint.

No weights are committed. No tokenizer artifacts are committed. No raw public corpus, cleaned public corpus, processed training text, teacher raw disallowed outputs, secrets, root DOCX/PDF files, `data/public_ingestion`, or `training/current` promotions are committed.

R27A6 introduces no runtime external dependency. Live external LLM APIs and Doubao are disabled by default. Optional live teacher usage, if separately configured with explicit flags and environment variables, is training-time candidate/probe infrastructure only and is not part of the product runtime.

The product-candidate dialogue readiness report is not product admission. It is an engineering signal for whether a later R27B browser/runtime packaging experiment is worth considering.
