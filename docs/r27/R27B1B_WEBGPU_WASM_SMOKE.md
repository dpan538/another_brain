# R27B1B WebGPU WASM Smoke

R27B1B adds a capability report command:

`npm run report:r27b1b-browser-capabilities`

The report checks whether WebGPU, WebAssembly fallback, worker support, same-origin loading, and static budget paths are present. ONNX WebGPU remains an experimental mode and is not bundled or required for this smoke.

Browser smoke is runtime packaging evidence only. It is not quality evidence and not browser model admission.
