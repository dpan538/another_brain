# R27A2 Public Corpus, Distillation, And Model Engineering

R27A2 moves another_brain from audit-only review toward a regular mini LLM engineering track. Public corpora are now a required training pillar, but every source must carry license, access, provenance, PII, CoT, hidden-prompt, secrets, eval-leakage, and old-question-pack guard status before use.

another_brain remains a memory-backed personal answer surface, not a generic customer-service assistant. The target path is Chinese-first, project-trained, from-scratch decoder LLM work that may later become a same-origin static browser artifact after separate admission. R24/R25/R26/R27 gates remain safety and regression infrastructure, not the main intelligence layer.

R27A2 does not approve product training, phase_4, release checkpoint admission, browser model admission, remote model-weight downloads, external LLM API calls, Doubao automation, raw public shard commits, or weight commits.

The registry is committed at `data/training_registry/public_corpus_registry.json`. Raw samples, cleaned samples, tokenizer artifacts, checkpoints, and run logs live only under ignored `artifacts/r27a2/`.

The curriculum path combines available public samples when license/access pass with approved R26E/R26G user-answer anchors, RAG/evidence rows from `knowledge_sources`, deterministic symbolic reasoning rows, and value/aesthetic rows. Blocked public sources are recorded honestly and are not faked.
