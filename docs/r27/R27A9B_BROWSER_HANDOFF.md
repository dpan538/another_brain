# R27A9B Browser Handoff

The browser handoff lives at `artifacts/r27a9b/handoff/R27_BROWSER_CANDIDATE_HANDOFF.json` and is ignored by Git. A safe tracked summary is written to `data/training_registry/r27a9b_browser_handoff_summary.json`.

The handoff is for B-line engineering evaluation only. It includes checkpoint path, checkpoint hash, tokenizer path, model size, optimizer-token evidence, losses, safety signals, budget fit, and explicit non-claims.

The handoff does not admit a product model and does not authorize browser admission. B-line must still verify static packaging, runtime behavior, and product readiness before any user-facing claim.
