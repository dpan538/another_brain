# R27A8B Evaluation And Handoff

R27A8B evaluation reports optimizer tokens, wall-clock, optimizer-token throughput, train/dev/heldout loss, stage losses, best checkpoint metadata, dialogue readiness, RAG honesty, collapse risk, Chinese-first behavior, and the 100MB budget.

The optional browser handoff path is:

`artifacts/r27a8b/handoff/R27_BROWSER_CANDIDATE_HANDOFF.json`

It is written only when the campaign is structurally safe and dialogue readiness is a candidate. The handoff is engineering-only and does not admit a product model, browser artifact, or release checkpoint.
