# R27B8 Non-Claims

R27B8 does not claim or create:

- product model
- product model admission
- browser admission
- release checkpoint
- committed model weights
- committed tokenizer artifacts
- committed exported assets
- committed quantized shards
- committed ONNX assets
- backend inference
- Vercel Function or Edge inference
- external LLM API
- Doubao integration
- hosted vector store

R27B8 only adds static browser asset cache and shard loader resilience for future same-origin candidate assets.
