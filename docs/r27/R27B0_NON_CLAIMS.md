# R27B0 Non-Claims

R27B0 does not claim or ship:

- product model
- model weights
- tokenizer artifact
- backend inference
- external LLM API
- Doubao integration
- browser model admission
- product model admission
- release readiness
- hosted vector store
- external runtime storage dependency

The shell is mock runtime only. It is a static product skeleton for the future memory-backed personal answer surface.
