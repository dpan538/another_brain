# R27A3 Non-Claims

R27A3 is an engineering-only public corpus, tokenizer, and model-lab pilot.

- It is not product training.
- It is not formal decoder training.
- It is not phase_4.
- It is not a product model.
- It is not a release checkpoint.
- It commits no weights.
- It commits no tokenizer artifacts.
- It commits no raw public corpus.
- It commits no processed public training text.
- It adds no browser runtime external dependency.
- It calls no external LLM API.
- It calls no Doubao service and does not automate Doubao desktop.

The R27A3 approval marker is consumed and inert after the single bounded engineering run.
