# R29A2 知识外挂与 150M 就绪门槛

R29A2 把知识扩展分成三个互不混淆的层：

1. 同源静态知识包：懒加载卡片、来源、许可、检索分数和证据状态；它提高事实召回，但不替代模型推理。
2. 本地会话上下文：用户手动导入、内存内使用、可清除、默认不持久化，且绝不进入训练语料。
3. 知识—对策课程：用项目自写且留出集隔离的卡片训练“结论 → 依据与不确定性 → 分级对策 → 边界”。

外部资料只能先变成带来源/许可的简短候选卡，再经过审查；禁止把未审查网页、论文全文、私有材料、评测题或外部模型输出直接放进训练。

`new_150m_estimate` 目前只是参数估算，尚无选定结构。q4 估算权重约 82.3MB，而把现有静态壳、分词器、RAG、清单与安全余量一起计算后约为 132.5MB，超过 100MB 上限约 32.5MB。因此 150M 当前只能作为本地研究候选，不能作为浏览器静态包升级。

更早的门槛是浏览器 q4 的真实前向：当前 worker 仍是 embedding + position + lm head 的前向 smoke，没有执行 transformer blocks。只有真实前向、150M 架构选择、内存/延迟测量和完整包预算都通过后，才能启动 150M 有界研究 smoke；即使通过，也不授予产品或发布资格。

```sh
npm run r29a2:knowledge-addon-readiness
```
