# R29A1 96M 知识与对策长期训练

R29A1 是在 R29A0 的最佳工程检查点之后进行的受控长期周期，不是浏览器、产品或发布准入。

- 模型：`new_96m`；仅在本机 MPS 上训练。
- 语气：中文、直接、有判断；固定回答顺序为“结论 → 依据与不确定性 → 分级对策 → 代价或边界”。
- 语料：由项目自写的知识—对策模板在本地 `artifacts/r29a1/training_mix/` 生成；不抓取、不提交原始文献或外部文本。来源链接只作为许可/出处记录。
- 留出集：使用完全不同的知识卡（代理指标、混杂、可逆性、分布差异），不得进入训练集。
- 预算：最多 400,000 个 assistant target token；每 50,000 token 评估；最多保留 3 个检查点；最多 4 小时。
- 终止：留出损失比历史最佳差 5% 以上、探针下降超过 0.05、连续两个非改进段、非有限损失、MPS/磁盘/批准标记失败、预算或时间到达。

R29A1 的完整条件是：零角色前缀泄漏、每个独立知识—对策探针至少 0.70、平均至少 0.80，并且没有留出集回退。即便满足，也只产生下一次评审输入，不产生产品、浏览器或发布资格。

命令：

```sh
npm run r29a1:create-campaign-marker
npm run r29a1:run-knowledge-countermeasure
```
