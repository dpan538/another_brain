# R28RT2 Non-Claims

R28RT2 does not claim:

- product model
- product admission
- browser admission
- release checkpoint admission
- phase 4 approval
- training
- backend inference
- Vercel Function or Edge inference
- external LLM API
- Doubao
- hosted vector store
- exact tokenizer vocabulary decode

The q4 runtime remains experimental. The readable display codec is for smoke and UI readability only.
