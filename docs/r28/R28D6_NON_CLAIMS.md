# R28D6 Non-Claims

R28D6 does not claim:

- product model
- product admission
- browser admission
- release checkpoint admission
- Vercel preview pass
- release readiness
- quality readiness
- phase 4 approval
- training
- new model assets
- new shards
- raw checkpoints
- backend inference
- external LLM API
- Doubao
- hosted vector store

R28D6 only packages the latest static q4 candidate into a final Vercel preview and main merge candidate branch.
