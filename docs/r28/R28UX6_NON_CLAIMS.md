# R28UX6 Non-Claims

R28UX6 is a front-end UX split only.

## Explicit Non-Claims

- not product model
- not product admission
- not browser admission
- not release checkpoint
- no training
- no new model assets
- no q4 shard changes
- no backend inference
- no external LLM API
- no Doubao
- no hosted vector store

## Static Boundary

The work stays inside the static browser preview. It does not download weights, train tokenizers, train models, parse root DOCX/PDF files, parse `data/public_ingestion`, or connect to hosted inference.
