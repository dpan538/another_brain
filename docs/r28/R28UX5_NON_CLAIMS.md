# R28UX5 Non-Claims

R28UX5 is a UI split and loading UX change only.

It does not claim:

- product model admission;
- browser admission;
- release checkpoint admission;
- phase 4 approval;
- backend inference;
- external LLM API usage;
- Doubao usage;
- hosted vector store usage;
- training;
- new model weights;
- changed q4 shards;
- new tokenizer training artifacts;
- private raw data ingestion.

The R28UX5 UI keeps the existing `not product` badges and runtime non-claims. Chat Mode is simpler, but Dashboard Mode keeps the process evidence available for pre-merge inspection.
