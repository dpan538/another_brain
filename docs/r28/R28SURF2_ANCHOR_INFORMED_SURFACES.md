# R28SURF2 Anchor-Informed Surfaces

R28SURF2 makes frequent entry questions less stiff without training or changing model assets. It uses approved anchor summaries for response shape: compressed, bounded, evidence-aware, non-service voice, and stance without universalizing.

## What Changed

- Added SURF2 fuzzy intent modules under `src/browser_runtime/router/`.
- Added compositional fragment groups instead of fixed one-template answers.
- Updated runtime routing so micro-intents return fast without waiting for q4.
- Kept open questions on the q4/RAG/router/finalizer path.
- Added process trace fields for `intent_confidence`, `used_model_draft=false`, and `final_answer_source=router_surface`.

## Example Outputs

- `你好`: 你好，直接说。我会尽量短，但保留判断边界。
- `你是谁`: 我是鳄鱼。我是这个本地网页里的另一个大脑界面。我会尽量按鳄鱼的判断方式说话。
- `你是鳄鱼吗`: 是，可以这么叫我：鳄鱼。我是这个本地网页里的另一个大脑界面。
- `你从哪里来`: 我依赖本地静态资产、已审查锚点和有限的路由 surface。当前不依赖云端 LLM、Doubao 或后端推理，也不把问题发给外部模型。这只是本地静态 runtime 的回答 surface，不是 release checkpoint。
- `你能做什么`: 我适合做边界判断、证据整理、短回答、拒答和语义重构。普通开放问题仍会走 q4 草稿、轻量 RAG、路由和 finalizer。我会尽量短，但不把判断轴压没。
- `你是不是 AI`: 我是鳄鱼。我是这个本地网页里的另一个大脑界面。如果你问是不是 AI：是，本质上是本地静态 runtime 里的小模型、检索和路由界面；不是已 admission 的产品模型。
- `证据不足怎么办`: 证据不足时，我会先说不足，而不是把猜测说成确定。如果缺证据，我会说明缺口。
- `你会怎么判断审美问题`: 好看不只是不出错，也可能是某种准确的不舒服。价值判断要先承认它有立场。

These examples are generated by deterministic composition, not a broad answer bank.
