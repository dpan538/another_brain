# R28M1 Non Claims

R28M1 does not claim:

- Product model.
- Product admission.
- Browser admission.
- Release checkpoint.
- Backend inference.
- Vercel Function or Edge inference.
- External LLM API.
- Doubao.
- Hosted vector store.
- Raw checkpoint committed.
- Unquantized weights committed.
- Training corpus committed.
- Tokenizer training artifact committed.
- `phase_4` approval.

The q4 static assets are engineering/pre-admission assets only.
