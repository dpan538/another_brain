# R28PR0 Non-Claims

R28PR0 does not claim:

- Product model admission.
- Browser admission.
- Release checkpoint admission.
- Backend inference.
- External LLM API use.
- Doubao use.
- Hosted vector store use.
- Training.
- Automatic merge.

R28PR0 also does not approve phase 4, product admission, browser admission, or release checkpoint admission.
