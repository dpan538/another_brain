## Surface Categories

The anchor structure supports bounded categories for greeting, identity, origin, capability, AI boundary, relation, evidence boundaries, malicious instruction resistance, value judgment, aesthetic judgment, abstract meaning, safe smalltalk, and unknown open questions.
