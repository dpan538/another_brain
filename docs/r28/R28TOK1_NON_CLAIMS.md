# R28TOK1 Non-Claims

R28TOK1 does not claim:

- product model
- product admission
- browser admission
- release checkpoint admission
- Vercel preview pass
- release readiness
- quality readiness
- phase 4 approval
- training
- new model weights
- new q4 shards
- raw checkpoint
- tokenizer training artifact
- raw, clean, or processed corpus
- eval prompt use
- backend inference
- Vercel Function or Edge inference
- external LLM API
- Doubao
- hosted vector store
- answer bank

Tokenizer admission in R28TOK1 is runtime compatibility only. It makes exact encode/decode available to the static q4 experimental runtime and leaves product/browser/release admission to later explicit gates.
