# R28P1 Demo Script

Use this script for the prelaunch demo only.

1. Open the static chat shell route: `/another_brain_chat/`.
2. Point out the `Local only` and `No backend inference` badges.
3. Point out the delivery mode: `demo_static`.
4. Point out candidate route status: `product_path_engineering_candidate`.
5. Point out the non-product warning.
6. Send a short Chinese prompt about another_brain browser memory or local evidence.
7. Open the evidence drawer and show static demo RAG evidence.
8. Import a small local context packet through the local context bridge.
9. Send another prompt and show the local-session context effect.
10. Clear the local context and show the bridge returns to session-only empty state.
11. Point out asset cache status: no real model assets are loaded.
12. Point out release blockers: real assets/admissions/Vercel preview/main merge are still pending.

Do not say this is a product model. Do not say browser admission is complete. Do not say release checkpoint admission is complete.
