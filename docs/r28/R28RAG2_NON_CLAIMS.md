# R28RAG2 Non-Claims

R28RAG2 is a lightweight static RAG productization layer only.

It does not claim:

- product model
- product admission
- browser admission
- release checkpoint admission
- phase_4 approval

It does not add:

- training
- new model weights
- new q4 shards
- raw checkpoints
- tokenizer training artifacts
- private raw data
- backend inference
- Vercel Function or Edge inference
- external LLM API
- Doubao
- hosted vector store
- broad answer bank

Existing q4 static assets remain the draft path when available. R28RAG2 only improves static retrieval, evidence classification, provenance display, and hard-router handoff.
