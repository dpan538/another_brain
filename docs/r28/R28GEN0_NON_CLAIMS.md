# R28GEN0 Non-Claims

R28GEN0 does not claim:

- product model
- product admission
- browser admission
- release checkpoint admission
- Vercel preview pass
- product-quality generation
- tokenizer quality admission
- Phase 4 approval

R28GEN0 does not add or change:

- training
- model shards
- raw checkpoints
- FP32/FP16 weights
- tokenizer training artifacts
- ONNX or GGUF artifacts
- backend inference
- Vercel Function or Edge inference
- external LLM API
- Doubao
- hosted vector store
- answer bank
- private persistence

GEN0 is an answer-surface and deterministic-policy hardening pass only. It keeps the static q4 runtime experimental and preserves fallback behavior when generated text is unstable.
