# R28ANCHOR0 Non-Claims

R28ANCHOR0 is an audit-only inventory.

It does not add:

- training
- model weights
- q4 shards
- tokenizer artifacts
- raw checkpoints
- root DOCX/PDF parsing
- `data/public_ingestion` parsing
- external LLM API calls
- Doubao calls
- backend inference
- hosted vector store
- broad answer bank

It does not claim:

- product model
- product admission
- browser admission
- release checkpoint admission
- phase_4 approval

The generated summary stores metadata, counts, hashes, and sample ids only. It does not store raw private data, hidden prompts, chain-of-thought, secrets, or raw eval prompts.
