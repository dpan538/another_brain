# R28HOTFIX4 Abstract Value Fallback

The fallback surface is only used when q4 is not ready, q4 times out, q4 fails, or a safety boundary skips generation.

Style:

- short
- bounded
- not customer-service
- admits uncertainty
- gives a judgment
- no fake evidence
- no hidden chain-of-thought
- no product admission claim

Example for `你如何看待生与死？`:

“我会把它看成边界问题。生不是纯粹的开始，死也不是纯粹的结论；人能做的，是在有限时间里留下判断、关系和作品。说得太漂亮就假，完全说成虚无也偷懒。”

This is a fallback surface, not a broad answer bank.
