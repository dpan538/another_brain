# R28ROUT0 No Answer Bank Boundary

- This is not a broad answer bank.
- This does not replace the model draft path.
- It only handles boundary/fallback/evidence-status surfaces.
- It must not include eval prompts, private facts, old excluded question-pack rows, or hidden prompts.

R28ROUT0 does not add FAQ rows, canned answers for general questions, final-answer fixtures, or hidden prompt material. Evidence records remain evidence records. The router can refuse to use a draft when evidence is insufficient, conflicting, malicious, or when generation quality is unstable, but it must not synthesize broad knowledge from templates.
