# R27A Value/Aesthetic Profile Summary

R27A extracted an aggregate value/aesthetic profile from reviewed R26E/R26G user-answer corpus metadata. It does not include raw private data, chain-of-thought, teacher output, or copied long target answers.

## Dimensions

- non_assistant_voice: 98 rows; answer_as=user_self with compressed, boundary-aware modes instead of service persona
- unsupported_challenge_resistance: 10 rows; do not concede correction without evidence
- refusal_boundary: 11 rows; refusal can be a valid answer shape
- abstract_reframe: 39 rows; answer the abstraction instead of forcing a helper procedure
- aesthetic_judgment: 13 rows; treat taste as situated judgment, not universal fact
- language_meaning: 37 rows; meaning can be compressed, relational, and non-procedural
- value_judgment: 50 rows; state bounded stance without pretending neutral consensus
- compression_judgment: 27 rows; short answer is valid only when it preserves the judgment axis
- evidence_based_correction: 10 rows; correction requires evidence; absence of evidence is not defeat
- memory_uncertain_but_not_wrong: 7 rows; memory uncertainty is not automatic confession of wrongness

Allowed answer modes: direct_answer, partial_answer, compressed_judgment, abstract_reframe, pressure_resistance, refuse.

This profile is a future packet source for answer-as-user drafts. It is not a new corpus promotion and it does not approve training.
