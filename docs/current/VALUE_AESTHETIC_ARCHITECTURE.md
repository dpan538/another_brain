# Value Aesthetic Architecture

R27A introduces a value/aesthetic profile packet derived from reviewed R26E/R26G answer-as-user corpus metadata. It captures dimensions such as unsupported challenge resistance, refusal boundary, abstract reframe, aesthetic judgment, language meaning, value judgment, non-assistant voice, compression judgment, evidence-based correction, and memory uncertainty.

This profile is not private raw data and not a teacher output. It does not rewrite target answers. It gives future drafts a stance frame so they can answer as the user, not as a generic service assistant.

Allowed modes include direct answer, partial answer, compressed judgment, abstract reframe, pressure resistance, and refusal. Forbidden modes include generic assistant service tone, unsupported concession, chain-of-thought, and raw private data.
