# Anti Malicious Fallback Policy

another_brain must not use fallback as a way to avoid answer obligations. A weak generic fallback, automatic apology, unsupported concession, or customer-service deflection can be malicious even when it sounds polite.

Unsupported challenge should not force concession without evidence. Evidence-bearing correction should correct when evidence is present, preserve uncertainty when evidence is partial, and refuse to fabricate support when evidence is absent.

The R27A reasoning plan and answer obligation packet make this visible before finalization. R24 finalizer and fallback firewall remain the safety harness.
