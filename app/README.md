# efish other

`type, write, chat.`

The rebuilt product surface: a React + Vite PWA. It is self-contained in this
directory and does not touch `web/` or the live deployment.

```bash
npm install
npm run dev        # http://127.0.0.1:5190
npm run build      # dist/, with service worker and manifest
npm test           # engine tests, no network and no key
```

## Shape

- **Home** — `this is efish other, another.` Scroll down for the chat.
- **Chat** — one wavy-framed card of pages. You type in the typewriter face,
  efish writes back in bold, never more than two sentences. The system keyboard
  is never raised: the drawn keyboard is the only input, and it carries its own
  pinyin input method. A hardware keyboard drives the same keys.
- **About** — one screen.
- Logo top-left returns home and keeps the conversation. Memory lives in
  IndexedDB on the device for 30 days.

Hidden commands, typed into the card: `/key` (store a DeepSeek key on this
device), `/nokey`, `/forget`.

## Engine (`src/engine`)

| File | Role |
| --- | --- |
| `persona_prompt.js` | efish's identity, reasoning and voice, compiled from `values_logic_profile_v0.4` |
| `answer_path.js` | commands → easter eggs → one streamed call, cut at the second sentence |
| `sentence_limit.js` | the two-sentence rule, enforced on the text itself |
| `deepseek_stream.js` | SSE transport; `direct` (key on device) or `proxy` (same-origin endpoint) |
| `easter_eggs.js` | local replies, every one a sentence the owner wrote |
| `pinyin_ime.js` | composition buffer and candidates |
| `memory_store.js` | 30-day local memory |

Set `VITE_EFISH_PROXY_URL` (for example `/api/chat`) at build time to answer
through a server-held key instead of a key on the device.

## Third-party data

`public/ime/pinyin_dict.json` is generated by `scripts/build_pinyin_dict.py`
from jieba's frequency list (MIT) and pypinyin (MIT). Fonts are the OFL
families in `@fontsource/*`. OPPO Sans 4.0 is referenced with `local()` only and
is never shipped: its licence forbids modification, which rules out subsetting,
and unmodified it is 22 MB.

## The key (R31B1)

The DeepSeek key is held by the server and relayed through one route, `/api/chat`
(`api/chat.js` → `server/chat_handler.js`). It is never in the bundle, a log or a response.

- Local: create `app/.env.local` with `DEEPSEEK_API_KEY=` and your key, then `npm run dev`.
- Vercel: set the project's Root Directory to `app` and add the environment variable
  `DEEPSEEK_API_KEY`. Optional: `EFISH_ALLOWED_ORIGINS` (comma separated) for extra domains.
- Without a key the route answers `503 not_configured`; the 鳄 board and the easter eggs still work.

See `docs/r31/R31B1_SERVER_KEY_AND_REBUS_HOME.md`.
